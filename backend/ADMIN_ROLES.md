# SureMandarin 后台权限

## 1. Super Admin — 站点所有者

当前账号：`530270794@qq.com`

拥有全部权限：网站内容、全局 SEO、课程、文章、会员、订单、PayPal、后台管理员、角色权限、系统配置和数据结构。

## 2. Editor — 内容与会员管理员

负责：文章、文章分类、新闻见解、学习技巧、中国文化、媒体库、FAQ、学员评价，以及普通会员姓名、邮箱、等级与状态的基础查看和维护。

不得授权：管理员管理、角色权限、系统设置、API Token、Webhook、PayPal 密钥、支付交易修改、退款、数据结构删除、全局 SEO 配置。

创建该管理员时，在 Settings → Administration panel → Users 中邀请她并选择 Editor。不要授予 Super Admin。

当前本地 Editor 权限已经收紧为：文章、文章分类、FAQ、学员评价、媒体库和前台会员基础资料；不包含删除权限，也不包含课程、订单、支付、退款、全局设置和后台权限管理。

## 3. Author — 投稿人员

只能创建和维护自己录入的内容，不能修改其他人的文章或系统内容。

## SEO 分工

- 全局 SEO、域名、站点验证和默认分享图：仅 Super Admin。
- 单篇文章的 SEO 标题、描述、关键词和分享图：Editor 可维护。
