# SureMandarin 后台操作指南

## 日常内容

- **首页管理**：修改首页幻灯片、推荐课程、推荐文章和学员评价。
- **课程**：维护六类课程的介绍、封面、访问等级和价格。
- **课程章节 / 课时内容**：上传视频、音频、PDF 和图文课程。
- **知识文章**：使用 Blocks 编辑器发布文章，完成后先预览再发布。
- **文章分类**：管理 Learning Strategies、Chinese Culture、Study Tips、News & Insights。
- **固定页面 / FAQ**：维护隐私政策、退款政策、会员协议和常见问题。

## 中英文内容

- 系统已启用 `English (en)` 和 `中文 (zh)` 两个内容语言，英文为默认语言。
- 文章、课程、首页、公告、FAQ、固定页面、全局设置、课程模块、课时、Banner、会员方案、推广和评价已配置为可多语言编辑。
- 新建或编辑内容时，在编辑页顶部切换语言；已有英文内容可通过“创建中文版本”生成中文版本，再分别填写中文标题、正文、封面和 SEO。
- 文章分类保持共用，不需要为中英文重复创建分类。
- Editor 和 Author 已获得中英文内容的编辑权限；SEO 字段仍仅对 Super Admin 开放。

## 用户与会员

- **User**：查看注册用户、VIP 等级、到期时间和封禁状态。
- **会员订阅**：查看 PayPal、Apple、Google、微信或人工赠送的订阅。
- **会员权益**：系统自动生成，普通运营人员不要直接修改。
- **课程加入记录 / 学习进度**：查看用户已经加入的课程和学习进度。

## 订单与支付

- **订单**：查看购买内容、金额、渠道和订单状态。
- **支付流水**：查看每一次扣款、退款或失败记录。
- **退款管理**：只有财务角色可以批准退款。
- **Webhook 日志**：技术人员排查支付同步时使用，普通人员无需操作。

## 推荐发布文章流程

1. 打开“知识文章”。
2. 点击“发表内容”（新建后请分别切换中文和 English，各编辑并保存一次）。
3. 填写标题、摘要、封面和正文。正文现在使用 Markdown 编辑器，可直接输入 `#` 标题、`-` 列表、链接、表格和代码块。
4. 选择文章分类和可访问会员等级。
5. 保存草稿。
6. 使用 Preview 检查前端效果。
7. 点击 Publish。

## 会员处理原则

- 不要直接修改用户的会员到期时间。
- 正常付费由支付 Webhook 自动升级或降级。
- 人工赠送必须建立 `Admin Grant` 订阅和对应权益记录，并填写原因。
- 退款后需要确认是否撤销对应会员权益。
