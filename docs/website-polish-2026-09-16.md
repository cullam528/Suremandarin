# 网站内容、登录体验与加载优化（2026-09-16）

## 本次调整

- 登录、注册、找回密码共用新版验证区：52px 滑块、44px 刷新按钮、原比例图片、清晰反馈、键盘方向键调整后 Enter 确认。修复快速拖动误判、旧请求覆盖新请求及验证过期仍显示成功。
- 三个账户表单共用请求处理，断网、网关返回非 JSON、45 秒超时均可恢复；保留填写内容，不自动重复注册或发送邮件。补充输入标签、隐私条款链接、密码确认检查，压缩手机端重复展示。
- 教师页面以已确认的 Jessica 资料和咨询匹配流程替换示例教师阵容；不假定老师可预约。
- 保留用户提供的 Patty、Daniel 两段故事以及 CMS 已发布评价；不再用代码自动补齐评价，不按数组序号覆盖 CMS 头像，未知验证状态不显示“已验证”。未删除 CMS 记录。
- `/en/resources`、`/zh/resources` 永久跳转到对应知识中心；`announcements` 永久跳转到对应新闻栏目。同步清理站点目录及 Footer 重复入口。
- Footer 社交链接优先读取全局设置；无合法 LinkedIn 地址时不显示该入口，不猜测用户资料链接。

## 性能与缓存

- 分离首页设置、课程目录、评价、全局设置的缓存读取。课程目录/联系页从依赖 5 类 CMS 数据减为 2 类；课程详情不再读取首页和文章。
- 首页分类封面只请求所需字段，不再拉取全部文章正文。审查时线上对应响应从 2738 字节减至 493 字节；这是单个请求体积，并非全站速度提升比例。
- 课程详情主体服务端渲染，仅 FAQ 保持小型交互组件。
- 手机端不下载已隐藏的首页幻灯与登录装饰图片，不运行隐藏幻灯的定时切换。
- 离线缓存升级为 v4：登录、注册、账户、API、RSC 与私有响应均不进入缓存；保留公开图片及允许缓存的 Daily 导航响应。只清理本应用旧缓存，不删除用户学习进度或数据库资料。

## 验证与边界

- 独立发布目录生产构建通过，生成 53 个静态页面；61 项隔离回归测试通过。
- 浏览器检查英文登录、中文注册及手机首页；390px 下无横向溢出，验证滑块实测高度 52px，隐藏 Hero 的图片源为内联透明图。
- 未操作真实账户登录/注册或发送密码重置邮件；验证码通过隔离模拟验证，不在生产自动完成验证码。
- 当前自建滑块仍属于轻量交互防护：它不是第三方反机器人平台，进程内限流/防重放不跨实例共享。生产应配置独立 `CAPTCHA_SECRET`；本次未改变现有密钥回退策略或新增服务收费。
- 已存在的 App/情景练习未提交开发内容保持原样，未混入本次发布；完整工作目录当时因该功能的共享模块路径处于变更中而构建失败，本次发布版本已单独构建验证。
- Render 免费实例的冷启动、网络距离与第三方 OAuth 配置不属于本次消除的瓶颈，不能据此保证所有访问秒开。
